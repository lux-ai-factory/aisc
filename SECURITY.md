# Security

## Reporting a vulnerability

Report a vulnerability privately to the maintainers of this repository, not in a public issue.
Say what is affected, how to reproduce it, and what an attacker gains.

## What to expect

The report is acknowledged within 3 working days and assessed within 10.

## Scope

This repository and its submodules. Services AISC runs but does not write (Postgres, Keycloak, MinIO, immudb,
RabbitMQ, Superset) are reported to their own projects.

## Supported versions

The `pilot` branch.
