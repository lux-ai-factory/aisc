# webapp file must be byte-identical to its base. The backend and the worker (apps/backend,
# apps/eval) are ours to change and are not listed.

#   base <repo> <commit>             origin/master of the repo, the base of feat/deployment-modes
#   <repo> <path> <labels>: <reason> a file feat/deployment-modes adds or changes on purpose
#
# Labels, comma-separated, name the area of the change:
#   modes         the configurator mode next to upstream's standalone one: project, session, install
#                 target and pages per mode
#   reports       the /report links removed: the AISC stack never serves /report, the report is the
#                 report composer's
#   wording       the start button says Launch Evaluation
#   project       each tab works on its own project: installs and saved selections never take another's
#   errors        failed runs and refused actions shown with their reason
#   dependencies  shipped dependencies above their vulnerable ranges
#   docs          the README
#   secrets       a plugin form's key kept as a project secret: a test only, the form is upstream's
#   helpers       models a test uses as tools (judge, attacker...) are the project's helper models, picked in
#                 the run form; the AI System offers no LLM components
#
# Derived with `git diff --name-only <base> HEAD` in apps/webapp.
